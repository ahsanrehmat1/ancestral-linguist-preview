# History Restored — Client Preview

Responsive English landing page for personal WWII family-history research. The client supplied the €59 Research Check, €249 Family History Report and €399 Complete Family Archive, with estimated delivery of 7–14 business days depending on complexity and available records.

This is a design preview. Package selectors show details, not a working checkout. No orders, payments, customer information or file uploads are accepted. The page is marked noindex.

The History Restored logo, real contact email, YouTube/Facebook links, business/legal materials and client-owned payment/form accounts are still pending. A text wordmark is used until the logo is supplied. Instagram links to the client-provided @hist.orycolour account.

The hero artwork is generated decorative imagery, not authentic historical evidence. Report examples are illustrative outlines, not completed customer reports. Fonts are served locally; open font licenses are included in assets/fonts.

Files are plain HTML, CSS and JavaScript, with no paid theme or build dependencies. Production sales hosting and payment setup are separate from this GitHub Pages preview.
